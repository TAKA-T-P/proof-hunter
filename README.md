# 証明ハンター Ver.0.2

**図形に隠された3つの根拠を探し出せ！**

## 1. アプリ概要

中学数学の「三角形の合同の証明」を、ゲーム感覚で練習できるWebアプリ。
証明文をいきなり書くのではなく、図形の辺や角をタップして「等しい部分」と「その理由」を見つけ、
3つの根拠が揃ったら合同条件を選んで証明を完成させる。

インストール・ログイン不要。PC・スマートフォン・タブレットのブラウザで動作する静的Webアプリ（ビルド不要）。

Ver.0.2 では、収録問題を15問・5ステージに増やし、三角形の対応の確認、苦手な問題の復習、証明完成後の解説を追加した。

## 2. 開発目的

- 証明を書く前段階の思考（どこが等しいか・なぜ等しいか・どの合同条件か）を、短いテンポで繰り返し練習できるようにする。
- 数学が苦手な生徒でも、証明への心理的ハードルを下げて取り組めるようにする。
- 図形から必要な情報を見つけ、理由を考え、合同条件を判断できる力を育てる（証明文の暗記ではない）。

## 3. 対象学年

- 中学2年生（図形の合同・証明の初学者）
- 中学3年生（証明の復習）
- 証明が苦手な生徒

## 4. 基本的な遊び方

1. ステージを選び、問題を選ぶ（どのステージ・どの問題からでも挑戦できる）。
2. 「辺選択」なら **辺** を、「角選択」なら **角（角の内側）** を2つタップ → 等式の候補（例：`AB＝CB`）が表示される。
   辺選択では辺だけ、角選択では角だけがタップに反応するので、頂点付近でも誤選択しない。
3. **等しい理由** を選び、「根拠を確定」。等式と理由の両方が正しければ根拠スロットに登録される。
   - 共通な辺・共通な角は、同じ辺（角）を2回タップする（`BD＝BD`）。選択中の表示が赤に変わり、3回目のタップで選択解除。
4. 3つの根拠が揃ったら **合同条件** を3択から選んで「決定」。
5. 「証明成功！」→ 完成した証明文と「今回のポイント」を確認する（式・理由をタップすると図の該当部分が光る）。
6. 困ったら「ヒント」（3段階）や、図の下の「△ 三角形を確認」（対象の三角形と対応する頂点を表示）を使う。

評価：★★★ ミス0・ヒント0 ／ ★★ ミス2回以内かつヒント1回以内 ／ ★ その他。

## 5. 画面構成・画面遷移

| 画面 | URL | 内容 |

```text
タイトル ─ はじめる ─→ ステージ選択 ─→ ステージの問題一覧 ─→ 問題プレイ ─→ 証明完成
   │                     │                                      ↑            ├ 次の問題へ（同じステージ内）
   │                     └→ 苦手な問題 ─────────────────────────┘            ├ 次のステージへ（ステージ最後の問題）
   └ つづきから（最後に挑戦した問題） ─────────────────────────────────→      └ ステージ選択へ
```

- スマートフォン縦画面（幅899px以下・縦向き）：画面上部（タイトルバー・図・ボタン）を固定し、図の右にボタンを縦3×横2で配置。問題文・解答パネル・スロットは下部でスクロールする。
- スマートフォン横画面など：1カラム（問題文 → 図 → 操作）。
- 幅900px以上：2カラム（左：問題文・図形、右：解答パネル・スロット）。
- 画面はURLハッシュで管理しているため、ブラウザの「戻る」でも状態が崩れない。プレイ画面を開くたびに新しい状態で始まる。

## 6. 実装済み機能

### Ver.0.1 からの機能

- タイトル／あそびかた／問題プレイ／証明完成の各画面
- SVGによる図形描画（画面幅に合わせて拡大縮小、縦横比維持）
- 「辺選択」「角選択」モード。辺選択では辺の操作領域だけ（実線より太い透明な領域。図が縮小表示されても画面上で約32px以上）、角選択では角の操作領域だけ（角の内側の扇形。辺と競合しないので大きめ）を置く。角選択中は選べる角に点線の円弧を表示
- 印つけモードでは、選んだ印の種類（辺の印／角の印のどちらか一方）に合う要素だけがタップに反応する。消すモードでは辺と角の両方（頂点付近は角を優先）
- 選択中の辺は黄色で強調、角は扇形＋円弧＋2本の辺を強調
- 同じ要素の再タップで選択解除、2つ選択済みで別の要素をタップすると選び直し、辺選択⇔角選択の切り替えで選び直し、「選択解除」ボタン
- 同じ辺・角の2回タップで共通な辺・共通な角（選択表示が赤）。理由に「共通な辺だから」／「共通な角だから」が出る。「根拠を確定」「決定」ボタンは赤
- 等しい理由の選択（問題ごとに3〜4択）と「根拠を確定」での判定
- 根拠の登録（順不同）・重複防止・登録済み根拠タップで図を強調
- 合同条件の3択と判定（根拠の組と三角形の対応から条件を導いて照合）
- 証明成功の演出と完成証明文（集めた順に関係なく標準的な順序で表示）
- 段階式ヒント（未発見の根拠を優先、3段階、使用回数を記録、評価に反映、段階2以降は図の該当部分が光る）
- 印つけ（辺：1〜3本線、角：円弧1〜2本）、消す（1つずつ／すべて）、根拠登録時の自動表示の印（緑、生徒の印とは別管理）
- 正解・不正解のフィードバック（理由だけ違う場合は等式を残して理由を選び直せる）
- ミス回数・ヒント回数・★評価、LocalStorage への進捗保存（使えない環境でもプレイ可能）
- Web Audio API による効果音（ON/OFF、初期ON）、`prefers-reduced-motion`（視差効果を減らす）対応

### Ver.0.2 で追加・変更

- **ステージ制**：5ステージ×3問＝15問。ステージ選択 → ステージの問題一覧の2段階。解放条件はなく、どの問題からでも挑戦できる。クリア済み・未クリアは色と表示で区別
- **ステージクリア**：そのステージの全問題が初めてそろったときだけ「STAGE CLEAR！」の演出と、証明完成画面の「次のステージへ」ボタンを表示（クリア済みのステージを繰り返しても大きな演出は出さない）
- **三角形を確認**：図の下のボタンで、証明する2つの三角形を色分け（青・黄、点線の輪郭）し、2つの三角形を取り出して並べた小さな図と、対応する頂点（同じ色＝対応、例 A↔C）を表示する。三角形を重ねる演出はしない
- **苦手な問題に挑戦！**：未クリア・最高評価★★以下の問題だけを一覧表示（★★★は除外）。評価が上がると自動で対象から外れる
- **証明完成後の解説**：問題ごとの「今回のポイント」（`explanation`）と学習のポイント。証明文の **式** をタップすると辺・角が光り、**理由** をタップすると辺・角に加えて、錯角・同位角なら使った平行線も光る
- **次の問題へ**：同じステージ内の次の問題へ進む。ステージ最後の問題では次のステージを案内する
- **操作性**：選択中のモードのボタンを金色の枠で強調し、図の枠の色もモードごとに変える。根拠発見時は根拠数が弾む。3つそろうと合同条件の欄が光り、画面内に入るようにスクロール。理由の選択肢を少し大きくした（高さ40px）
- **図形の表現の拡張**（問題データから共通処理で扱う）
  - 途中に点がある長い辺（例：D が AB 上にあるときの AB）。D〜B の部分をタップすると AB 全体が選ばれ、印は辺に沿った補助線の上に表示
  - 2組の平行線（矢印1つ・2つ）
  - 角の操作領域は、隣の頂点・線の交点・角の内側にある頂点との距離から自動で大きさを決め、重ならないようにする

### 判定メッセージ一覧

| 状況 | メッセージ | ミス |
|---|---|---|
| 正解 | 根拠発見！ | — |
| 等式が誤り | この2つが等しいとは、まだ言えないよ！ | ○ |
| 等式は正しいが理由が誤り | 等しい辺（角）は見つけられたね！ でも、理由をもう一度考えてみよう。 | ○ |

## 8. 技術構成

- HTML5 / CSS3 / JavaScript（ES2015程度、フレームワーク・ビルドなし）
- SVG（辺・角ごとに操作領域を持つ）
- LocalStorage（キー：`proofHunter.v1`）
- Web Audio API（効果音）
- テスト：Node.js 組み込みのテストランナー（`node:test`、追加パッケージ不要）

各JSは `window.PH` 名前空間に機能を登録する。ES Modules を使っていないので、`index.html` をダブルクリックして `file://` で開いても動作する。
DOMに依存しないファイル（problems / geometry / validation / hints / storage / game）は Node から `require` してテストできる。

## 10. 問題データの構造と追加方法

`js/problems.js` の `PH.problems` 配列にオブジェクトを1件追加する。判定・描画・ヒント・証明文はすべて共通処理がこのデータを参照するので、問題ごとの if 文は不要。配列はステージ順に並べ替えられる（同じステージ内は書いた順）。

```js
{
  id: 'p16',                     // 一意なID（URL #/play/p16 に使われる）
  number: '16',
  title: '〇〇を見つけろ！',
  difficulty: 2,                 // 1〜3
  stage: 5,                      // 所属ステージ（PH.STAGES の id）
  statement: '…であることを証明しよう。',
  given: ['AB＝DC', '∠ABC＝∠DCB'],  // 仮定（表示用）
  conclusion: '△ABC≡△DCB',      // triangles と同じ順番で書く（検証される）
  // 対応順に並べた2つの三角形（同じ位置の頂点どうしが対応）
  triangles: [['A', 'B', 'C'], ['D', 'C', 'B']],
  figure: {
    viewBox: [0, 0, 400, 400],
    points: { A: { x: 80, y: 60, label: [-16, -16] }, ... },  // label: 文字の位置（点からのずれ）
    lines: [['A', 'O', 'C']],    // 3点以上が一直線上に並ぶ線（角の同一性判定に必須。並び順も検証される）
    segments: ['AB', 'BC', { name: 'AC', hit: ['O', 'C'] }, ...],
                                 // 描画・選択できる辺。途中に点がある長い辺は hit でタップする部分を指定
    angles: ['ABC', ...],        // 選択できる角（真ん中が頂点、180°未満の角）
    parallel: [['A', 'D', 1], ['B', 'C', 1], ['A', 'B', 2], ['D', 'C', 2]],
                                 // 平行の矢印 [始点, 終点, 組番号]。同じ組は同じ向き。組番号の数だけ矢印を重ねる
  },
  reasons: ['given', 'common', 'vertical'],   // 表示する理由の選択肢（PH.REASONS のキー）
  evidence: [                    // 標準的な証明の順に並べる（証明文はこの順で表示）
    { id: 'e1', items: ['AB', 'DC'], reason: 'given', label: 'AB＝DC', mark: 1 },
    { id: 'e2', items: ['∠ABC', '∠DCB'], reason: 'given', label: '∠ABC＝∠DCB', mark: 1 },
    { id: 'e3', items: ['BC', 'CB'], reason: 'common', label: 'BC＝CB', mark: 'common' },
    // 平行線の理由では parallelGroup（どの組の平行線か）と、証明文の書き方 proofReason を指定できる
    // { id: 'e2', items: ['∠BAC', '∠DCA'], reason: 'alternate', parallelGroup: 2,
    //   proofReason: 'AB∥DCより、平行線の錯角は等しいから', ... }
  ],
  extraTruths: [                 // 正しいが今回は使わない関係（その理由で答えたらミスにしない）
    { items: ['∠AOD', '∠BOC'], reason: 'vertical' },
  ],
  congruence: 'SAS',             // 'SSS' | 'SAS' | 'ASA'
  proof: { intro: '△ABCと△DCBにおいて' },
  hints: {                       // 根拠IDごと＋'congruence' に3段階。focus は図で光らせる要素
    e1: [{ text: '…' }, { text: '…', focus: ['AB', 'DC'] }, { text: '…', focus: ['AB', 'DC'] }],
    ...
    congruence: sasHints('∠ABC', '辺ABと辺BC'),   // 共通文のヘルパー（sssHints / sasHints / asaHints）
  },
  explanation: '…',              // 証明完成画面の「今回のポイント」
  learningPoints: ['…'],
}
```

ポイント：

- `items` の書き方：辺は `'AB'`、角は `'∠ABC'`。`AB`/`BA`、`∠ABC`/`∠CBA`、一直線上の別名（Oが AC 上なら `∠BAO`＝`∠BAC`）は自動で同一視される。
- 角の名前は必ず3文字。角は「頂点＋2本の半直線」で識別するので、一直線上に3点以上ある線は `figure.lines` に必ず書く。
- 「結論から導かれる関係」（対応する辺・角のうち根拠でないもの）は `triangles` から自動で判定されるので登録不要。ただし、結論を使わずに言える正しい関係（対頂角・錯角など）は `extraTruths` に登録して、ミスにならないようにする。
- ステージを追加する場合は `PH.STAGES` に `{ id, title, theme }` を追加する。
- 理由のID：`given`（仮定より）、`common`（共通な辺だから）、`commonAngle`（共通な角だから）、`vertical`（対頂角）、`alternate`（錯角）、`corresponding`（同位角）。同じ要素を2つ選んだときは、`common`／`commonAngle` が選択肢に自動で追加される。新しい理由は `PH.REASONS` に `label`（選択肢）・`short`（スロット）・`proof`（証明文）を追加する。

### 問題追加の手順

1. 図の座標を、仮定と結論が成り立つように決める（2つの三角形は実際に合同に描く）。
2. 上の形式でデータを追加する。
3. `npm test` を実行する。`verifyAll` / `verifyProblem` が次を検出する。
   - 図にない・選択できない要素、理由が選択肢にない、ヒント・解説・ステージの不足、問題IDの重複、問題のないステージ
   - 結論の表記と `triangles` の対応順の不一致、つぶれた三角形、`lines` の点が一直線上にない
   - **図の座標で測ると等しくない根拠・`extraTruths`**、**図の2つの三角形が合同に描かれていない**、平行の印が平行でない
   - 根拠の組から導いた合同条件と `congruence` の不一致
   - 角の操作領域どうしの重なり（`v02.test.js`）
4. ブラウザで実際にプレイし、タップのしやすさを確認する。

## 11. 保存データの仕様

LocalStorage のキー `proofHunter.v1`（Ver.0.1 と同じキーで、そのまま引き継ぐ）。

```js
{
  version: 2,                    // Ver.0.2 で追加（Ver.0.1 のデータには無く、次の保存時に付く）
  problems: {
    p01: { cleared: true, bestStars: 3, minMisses: 0 },   // 問題ごとのクリア・最高評価・最少ミス
    ...
  },
  lastProblemId: 'p01',          // 「つづきから」の行き先
  sound: true                    // 効果音
}
```

- ステージのクリア数・★の合計・ステージクリア・復習対象は、保存せずに `problems` から毎回計算する（Ver.0.1 のデータでも正しく表示される）。
- 復習対象：`cleared` が false、または `bestStars` が3未満の問題。
- 壊れた値は安全な値（未クリア・★0）として読む。過去のプレイ内容は推測で補わない。
- LocalStorage が使えない環境ではメモリ上だけで動作する（画面を閉じると消える）。

## 12. 開発環境・起動方法・テスト

- 一番簡単な方法：`index.html` をブラウザで開く（ダブルクリック）。
- ローカルサーバーで開く場合（どれか1つ）：
  ```sh
  npm start                      # npx http-server（初回はダウンロードあり）→ http://localhost:8080
  python -m http.server 8080     # Python がある場合
  ```
- テスト（Node.js 18以上）：
  ```sh
  npm test                       # = node --test tests/*.test.js
  ```

### テスト項目

- `logic.test.js`：線分・角の同一性、等式の左右入れ替え、理由の誤り、重複、結論を根拠にできない、合同条件の誤り、辺選択/角選択、共通な辺・角の2回タップ、印つけ、ヒント、再挑戦の初期化、評価計算、保存
- `v02.test.js`：
  - 全問題のデータ検証（図の座標による数値チェックを含む）、15問・5ステージ・各3問、合同条件のバランス、ステージ順
  - 全15問それぞれについて：根拠を逆順に登録しても完成する、合同条件を誤るとクリアにならない、正しい等式でも理由が誤れば不正解、根拠にならない等式は正解にならない、完成証明文の内容
  - 結論から導かれる関係はどの問題でも根拠にできない、別ルートで使える正しい関係はミスにしない
  - 途中に点がある長い辺・共通な角の同一視
  - 角の操作領域どうしが重ならない（全問題・角選択/印つけの両方）、小さすぎない
  - Ver.0.1 の保存データの引き継ぎ、ステージのクリア数・★の合計、復習対象（未クリア・★★以下、★★★は除外、評価の更新で外れる）、壊れたデータ、LocalStorage が使えない環境

## 13. GitHub Pages公開方法

1. このフォルダをGitHubリポジトリにpushする（`index.html` がリポジトリ直下になるように）。
2. リポジトリの **Settings → Pages** を開く。

## 14. 今後の拡張予定

- 二等辺三角形・平行四辺形の性質を使う応用問題、直角三角形の合同条件
- 1つの問題で複数の有効な根拠セット・証明ルートを受け付ける（`validation.deriveCondition` は既に根拠の組から条件を導けるので、`evidence` を「候補」として増やし、3つの組で判定する形に拡張できる）
- 三角形の対応する頂点を自分で選ぶ問題（`triangles` の対応データと「三角形を確認」の表示を流用できる）
- 苦手な証明パターン（共通な辺・対頂角・錯角など）の分析（現在は問題単位の復習のみ）
- 制限時間モード、証明パズル（並べ替え）、穴埋め、自由記述、ランキング、問題作成エディタ
- 音声ファイル（`assets/sounds/`）・イラスト（`assets/images/`）の追加

## 15. 既知の制約事項

- 各問題の証明ルートは1種類のみ。別ルートで正しい根拠は、`extraTruths` に登録したものは「今回は使わない関係」としてミスにしない。登録していない正しい関係のうち、結論を使わないと言えないものは「結論から導かれる関係」または「まだ言えない」として扱う。
- 2段階の推論が必要な関係（例：p04 の ∠ABD＝∠ACD、p14 の ∠BDC＝∠CEB）は、1つの理由では言えないため不正解（「まだ言えないよ」）になる。
- 角は180°未満のみ対応。選択できる角は `figure.angles` に登録したもの（隣り合う2辺でできる角）に限られ、例えば問題01の ∠ABC（∠ABD＋∠DBC）は選べない。
- 途中に点がある長い辺（p14 の AB・AC）は、点より先の部分（D〜B、E〜C）をタップして選ぶ。その部分（DB・EC）を単独の辺として選ぶことはできない。
- 交わる線の交点に名前がない場合（p04・p14）、交点のまわりの角は選べない。
- 印つけで生徒がつけた印と根拠の自動表示の印が同じ辺・角に重なる場合は、自動表示（緑）を優先して表示する（生徒の印は内部に残る）。
- 「ヒント」は最終段階を繰り返し表示できるが、回数は新しい段階を開いたときだけ増える。
- プレイ途中で画面を離れると途中経過は保存されない（クリア記録と最後に挑戦した問題のみ保存）。
- ステージクリアの演出は「全問クリアがそろった瞬間」だけ表示する。Ver.0.1 のデータで既に全問クリア済みのステージは演出なしでクリア表示になる。
- 効果音はブラウザの自動再生制限により、最初の操作の後から鳴る。
- `∥` 記号はフォントによって `//` のように見えることがある。
